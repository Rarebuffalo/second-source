# Second Source

Every AI claim needs a second source.

Second Source independently checks whether AI agents did what they say they did,
using evidence from the systems they acted on, and re-checks that it stayed true.

The first focus is coding agents: claims such as "all tests pass" or "fixes #123"
in agent-authored pull requests are checked against CI and Git evidence.

Status: early development. See `docs/` for the strategy, PRD and technical specification.
